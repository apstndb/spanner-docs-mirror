This document describes the support requirements, software version support, and deprecation policy for Spanner Omni.

## Requirements for Spanner Omni support

To troubleshoot business-critical incidents, do the following before you contact Cloud Customer Care:

- Check that your environment is current and within the published end-of-support timeframes. For more information, see [Version support policy](https://docs.cloud.google.com/spanner-omni/support#version-support-policy) .

- Collect and share Spanner Omni diagnostics. For more information, see [Connectivity and diagnostics](https://docs.cloud.google.com/spanner-omni/overview#connectivity-development) .

## Version support policy

The following policies govern Spanner Omni software support and deprecation:

- To receive Spanner Omni support, you must sign up for [premium support](https://docs.cloud.google.com/support) .

- Spanner Omni support starts when you purchase a commercial license for the [Commercial edition](https://docs.cloud.google.com/spanner-omni/editions-overview#commercial-edition) .

- The support period for each subsequent long-term support (LTS) release that you install is one year starting from the release date of that LTS release.

- Google recommends that you install each LTS release within 60 days of its release date.

- Google provides support for each short-term support (STS) release until the date of the next STS or LTS release, whichever comes sooner. The support period for an STS release starts on its release date.
